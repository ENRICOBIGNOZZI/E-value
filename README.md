# Portfolio-aware alpha retirement and revival

Research workspace for the manuscript **When Should I Kill—and Revive—an Alpha?**

The project studies reversible allocation decisions using paired portfolio utility scores and sequential evidence. All mathematical proofs belong in the manuscript appendix. Empirical data are restricted to JKP. Simulated results and real-data results must be labeled separately; no performance, novelty, minimax, or deployment claims may be made without supporting evidence.

Implementation and reproducibility files are being added in this research update. Raw licensed data and credentials must not be committed.
